# 打击感 Demo

## 场景入口

打开并运行 `HitFeelDemo.unity`。场景包含几何体玩家、敌人、相机、灯光及 UGUI 控制面板，不需要加入 Build Settings。

## 操作

- 点击“测试攻击”发射一次目标弹体。
- 只有弹体实际命中敌人时才扣血并触发命中反馈；敌人移出弹道后不会触发反馈。
- 面板可滚动浏览 12 个独立开关：命中顿帧、命中音效、命中特效、敌人闪白、敌人击退、镜头震动、弹体拖尾、局部径向模糊、黑白、反色/色彩失真、冲击光圈和水墨效果。
- 在 `DemoManager` 的 `HitFeelDemoController` Inspector 中选择“普通”或“强打击”，使用同一个按钮对照；不改变伤害值和攻击流程。

## 默认参数

- 敌人生命值：1000，死亡后不销毁，便于重复测试。
- 每次命中伤害：10。
- 命中顿帧：0.06 秒；特效清理：2 秒。
- 命中特效使用场景原有 `Assets/Art/Effects/FX/gw/Hit.prefab`，在子弹实际命中敌人的表面位置播放；命中音效为 `Audio_BulletAtk.wav`。
- 敌人闪白：0.12 秒；击退距离：0.25，时长：0.12 秒。
- 镜头震动幅度：0.08，时长：0.12 秒。
- 拖尾：宽度倍率 `0.18`，显示时间 `0.22` 秒；普通屏幕反馈强度较低，结束后自动淡出。
- 水墨：主体尺寸 `0.85`，时长 `0.52` 秒，普通命中喷出 4 个墨点；强打击额外增加 5 个。
- 强打击对照：顿帧 `0.16` 秒、命中特效缩放 `1.25`、音量倍率 `1.15`、闪白 `0.16` 秒、击退 `0.4 / 0.16`、震动 `0.15 / 0.16`。
- 屏幕效果通过当前 URP Renderer Feature 渲染，仅在挂有 `HitFeelDemoScreenEffects` 的 Demo 相机效果播放期间执行。

反馈参数及资源均可在 `DemoManager` 的 `HitFeelDemoController` Inspector 中调整。
