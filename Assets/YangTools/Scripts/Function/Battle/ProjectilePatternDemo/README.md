# 投射物模式演示

打开同目录 `ProjectilePatternDemo.unity` 并运行。左侧按钮循环切换预设、排列和轨迹，点击“发射”观察弹幕；可启用目标移动及清空演示子弹。参数修改通过本目录的 SO 配置完成，运行时使用副本。

## 资产

- `Pattern.asset`：普通多发弹幕。
- `HitChain.asset`：命中后换到最近的未命中目标，最大派生深度限制链长。
- `DeathScatter.asset`：0.7 秒后消亡并产生扇形子弹。
- `FlightNodes.asset`：寿命均分 5 段，在内部 4 个节点向切线偏移 90 度派生扇形子弹。
- `Child.asset`：派生扇形子弹配置，可替换成其他投射物效果。
- `PatternBullet.prefab`：Trigger 球体碰撞器与无重力运动学 Rigidbody。

## 发射排列

| 模式 | 参数与含义 |
| --- | --- |
| Linear | 每排数量与横向间距 平行居中排列 |
| Directional | 从中心向 360 度等分方向发射 |
| Arc | 总角度范围内均分 单发沿中心方向 |
| AreaRandom | 位置半径内随机生成 并随机偏转方向 |
| OutsideIn | 首环半径处生成 朝固定中心飞行 |
| CircleRow | 按排数和半径间距排列 每排使用相同数量 |
| LaunchCircleRow | 向每排半径直线发射 到环后停留直至消亡 此规则优先于所选轨迹 |

## 飞行模式

| 模式 | 参数与含义 |
| --- | --- |
| Linear | 初始速度与恒加速度 减速至零后不倒飞 |
| Lobbed | 按弧高和时长飞到发射时确定的目标点 到点消亡 |
| Orbit | 围绕固定中心旋转 径向速度控制扩散或收缩 |
| Sine | 向前飞行并横向正弦偏移 使用振幅和赫兹频率 |
| Tracking | 持续追踪目标 用度每秒限制转向 目标丢失后直飞 |
| Lobbed2 | 初始仰角加重力轨迹 下降至发射高度后消亡 |
| Circle | 固定中心与半径的匀速圆周 从生成位置连续出发 |
| LaunchCircle | 先直飞 经三次曲线平滑转向 最后匀速圆周 |
| FlyAwayAndBack | 飞至指定距离后沿原路返回起点并消亡 |
| SpecifyTargetFlyLine | 只在出生时瞄准目标 不持续修正方向 |

所有排列在 XZ 平面展开 抛物线高度使用世界 Y 轴。圆周中心不会跟随施法者移动。无目标时使用技能指定点 零距离时使用基准方向和默认距离。

## 生命周期与命中

在 `ProjectileSkillEffect` 的 Odin 面板中配置命中、消亡和飞行节点效果列表。列表接受任意 `SkillEffect`，例如投射物、范围伤害或 Buff。

- 命中：成功造成伤害后触发。普通效果取得本次命中目标；派生投射物在搜索半径与目标层级中选最近的未命中对象，无下一目标时跳过该投射物。
- 默认额外穿透次数为 0。设为 N 时最多命中 N+1 个不同伤害对象。目标的多个碰撞体不会重复伤害，派生链排除沿途已命中对象和施法者。
- 消亡：穿透耗尽、阻挡、轨迹终点或有限寿命结束时执行一次。先执行命中列表，再执行消亡列表。禁用、外部 Destroy 和卸载场景不派生效果。
- 节点：有限寿命均分 N 段，只执行内部 N-1 个节点。低帧率跨越多个节点时补发，方向取对应节点处的运动切线。无限寿命禁用节点并提示。
- 原施法者、技能、武器来源和 SkillCastSession 继承到派生上下文，生成过程不重新扣资源或计算冷却。
- 每次根施放默认最多生成 512 发、派生深度最多 4，所有分支共享预算。到达限制后停止派生，已有弹体继续飞行。

旧的单发直线资产与 `SkillProjectile.Launch` 调用仍可用。目标层和阻挡层分别配置，默认阻挡层为空；演示场景不作为正式玩法关卡。
