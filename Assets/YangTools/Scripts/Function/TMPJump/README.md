# TMPJump 字符网格动画

## 功能与入口

[TMPJump.cs](TMPJump.cs) 使用 DOTween 为 TMP 可见字符分别创建位移、淡入和淡出动画，支持逐字延迟、循环、目标颜色与自定义缓动曲线。

## 依赖与配置

同物体需要 `TMP_Text`，项目需包含 DOTween 和 Odin。配置位移、持续时间、逐字间隔和缓动；播放前确保文本已生成有效字符网格。

## 最小接入

```csharp
GetComponent<TMPJump>().DoJump();
```

## 示例与限制

本目录没有演示场景。动画直接改写字符顶点和颜色；当前没有集中保存和取消各字符 Sequence 的入口，也未在停用时自动清理动画。重复调用、改变文本或销毁物体前应由接入方管理动画生命周期，避免多组动画争写网格。
